# Fluxos analog-first dentro do SilverBullet

## Captura livre → revisão → Journal

Continue usando papel comum. Datas e símbolos são opcionais durante a escrita; a revisão pode atribuir data ou título ao material sem contexto. O lote preserva a sequência das páginas. Uma nova data encerra a anterior e o resultado é incorporado no Journal nativo. A data de captura não substitui a data escrita.

Para menor atrito, prefira um lote por caderno/sessão, com datas explícitas quando puder. Sem evidência de contexto, revise em vez de deixar a IA inventar datas ou pais. O documento original permanece acessível pelo bloco incorporado e por sua página documental.

## Leitura em papel → Literature Note existente

Registre uma vez o alias curto `Ƶ Silva24-Mem` para a identidade real do Zotero. No caderno, escreva a referência no bloco pai: filhos herdam a referência e o projeto. A incorporação gera links nativos para a Literature Note, aproveitando os backlinks do SilverBullet em vez de copiar o trecho para várias páginas.

A nota bibliográfica continua editável; Zotero conserva a autoridade dos metadados. Na instalação compartilhada, o importador existente é reutilizado para a mesma biblioteca pessoal. Alias desconhecido permanece uma pendência de revisão.

## Planejamento em papel → tarefa local → Vikunja

Escreva `□` e revise antes de exportar. O ID local permite acompanhar a tarefa sem servidor. Bullets comuns filhos permanecem comentários; apenas filhos tarefas ganham relações remotas. Exportação é manual no MVP, com origem persistente e reconciliação de resultados incertos.

A folha imprimível devolve IDs ao papel. Uma captura posterior com `× T00001` permite revisar a conclusão sem apagar a marcação original. Alterar o estado da tarefa não altera o arquivo físico digitalizado. Não há sincronização bidirecional automática nesta versão.

## Ensaio em papel → página nativa

Use `:: Título` e `::end`, ou escolha o título na revisão. A página resultante é Markdown comum, com links de origem; continua no editor habitual do SilverBullet. Reimportação concluída não recria uma página movida. Reestruturar uma transcrição já incorporada exige reconciliação manual para preservar edições posteriores.

## Propostas para a próxima etapa

- Mostrar uma consulta de menções manuscritas na Literature Note, apoiada nos links e IDs canônicos já existentes.
- Criar templates de sessões de leitura/caderno com campos opcionais, sem exigir formulário durante a escrita no papel.
- Adicionar seleção gráfica de região e correção de árvore antes de incorporar.
- Adicionar uma fila explícita de atualização de blocos existentes, com comparação entre original, transcrição anterior e edição atual.
- Usar os eventos e templates nativos do SilverBullet antes de introduzir outro runtime de scripts.

Essas propostas não são funcionalidades concluídas. O caminho prioritário é validar um pequeno lote real e ajustar revisão/HTR antes de ampliar automações.
