# Native SilverBullet standard library

`Std/` is the unmodified standard library snapshot already used by this deployment, from SilverBullet 2.11.1, revision `1340f7369e782a9c99e898de75cd588051fdb7cd`. Source: https://github.com/silverbulletmd/silverbullet/tree/2.11.1/libraries/Library/Std . It supplies native Space Lua APIs and is mounted read-only by generated clean installations. Keep it aligned with the pinned SilverBullet image.
